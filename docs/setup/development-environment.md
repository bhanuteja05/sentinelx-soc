# Development environment

Prerequisites already installed for local SentinelX development. This document records the toolchain only; SOC stack and application setup come in later milestones.

| Tool | Role |
| --- | --- |
| **Git** | Version control for this repository |
| **WSL2** | Windows Subsystem for Linux, used as the Linux development environment |
| **Ubuntu** | Linux distribution running under WSL2 |
| **Docker** | Container runtime for future lab services |
| **Docker Compose** | Multi-container orchestration for future lab stacks |
| **Node.js** | JavaScript runtime for the planned React dashboard |
| **npm** | Node package manager |
| **Python** | Language for the planned backend and scripts |
| **pip** | Python package installer |

Do not install or configure Wazuh, Sysmon, Zeek, Suricata, Sigma, YARA, or application dependencies as part of this milestone.
